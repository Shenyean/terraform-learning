# terraform-learning
This repo would be reference for learning of terraform
Terra form make use of blocks, and there are different block types for different uses. 
These are the one that i know and use as off now: 
1. provider. configure a provider plugin ( aws , azure, GCP )
2. resource defines the infrastructure object to creat (e.g AWS EC2) 
3. data, reading data from the existing infra( e.g Ec2 instance id , VPC id )
4.variable
